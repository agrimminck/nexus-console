NEXUS_CONSOLE — SC Sound Files
================================
Place these files here to use real StarCraft sounds:

  click.ogg     — button click (SC UI click)
  run.ogg       — run start (short acknowledge)
  pass.ogg      — test pass (positive chime)
  fail.ogg      — test fail (negative tone)
  pin.ogg       — pin (high blip)
  queue.ogg     — queue add (medium blip)
  tab.ogg       — tab switch

SC2 sounds are in: <SC2 install>/SC2/Mods/Core.SC2Mod/Base.SC2Data/Sounds/ui/
Extract with: https://github.com/Kangerlussuaq/CASCExplorer

Falls back to Web Audio synthesis if files missing.
